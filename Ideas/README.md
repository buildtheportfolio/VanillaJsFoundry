## 🧩 Category 1 — DOM Manipulation & UI Components

### 1. Trie-Powered Autocomplete Engine
**Description:** A search input that suggests completions in real-time using a Trie data structure built from a large word list.
**Core JS Concepts:** DOM events, data structures (Trie), text node manipulation, keyboard navigation
**Difficulty:** Intermediate
**Unique Challenge:** Implementing the Trie traversal so suggestions appear under 16ms even with a 100k-word dictionary — requires lazy node expansion and capped result sets.

---

### 2. Infinite Virtual Scroll
**Description:** Renders a list of millions of items smoothly by only painting the ~20 rows visible in the viewport at any time.
**Core JS Concepts:** IntersectionObserver, DOM recycling, scroll events, computed layout math
**Difficulty:** Intermediate
**Unique Challenge:** Keeping scroll position stable when items above the viewport are unmounted/remounted — requires height caching and a spacer sentinel element.

---

### 3. Schema-Driven Form Builder
**Description:** Takes a JSON schema as input and dynamically generates a fully validated, accessible HTML form — no hardcoded fields.
**Core JS Concepts:** JSON parsing, recursive DOM construction, Constraint Validation API, event delegation
**Difficulty:** Intermediate
**Unique Challenge:** Supporting nested object/array fields that can be added/removed dynamically while keeping validation rules correctly scoped.

---

### 4. Multi-Step Wizard with State Machine
**Description:** A multi-page form wizard whose navigation logic is driven by an explicit Finite State Machine rather than ad-hoc conditionals.
**Core JS Concepts:** State machine pattern, history management (pushState), form validation, CSS transitions
**Difficulty:** Intermediate
**Unique Challenge:** Implementing "guard conditions" so that certain transitions (e.g. "next") only fire if the current step's data is valid — without spaghetti if-chains.

---

### 5. CSS-in-JS Theme Engine [RARE]
**Description:** A pure JS module that lets users define theme tokens (colors, spacing, fonts) and injects them as scoped CSS Custom Properties — live, with no build step.
**Core JS Concepts:** CSS Custom Properties API (`element.style.setProperty`), CSSStyleSheet constructable, Proxy objects
**Difficulty:** Advanced
**Unique Challenge:** Using Constructable Stylesheets (`new CSSStyleSheet()`) to inject and hot-swap rules without ever touching the DOM's `<style>` tags.

---

### 6. Accessible Modal Stack Manager
**Description:** A utility that manages layered modals: focus trapping, scroll locking, ARIA attribute toggling, and proper Escape-key dismissal for a stack of N open modals.
**Core JS Concepts:** Focus management, ARIA attributes, event bubbling, WeakMap for private state
**Difficulty:** Intermediate
**Unique Challenge:** Correctly restoring focus to the previously-focused element when a modal closes, even if the triggering element is no longer in the DOM.

---

### 7. Rich Text Editor (from scratch) [RARE]
**Description:** A WYSIWYG editor built on `contenteditable` that supports bold/italic/links/lists, serializes to clean HTML, and does NOT rely on `document.execCommand`.
**Core JS Concepts:** Selection & Range API, `contenteditable`, MutationObserver, clipboard events
**Difficulty:** Advanced
**Unique Challenge:** Implementing bold/formatting by programmatically wrapping `Range` selections in `<strong>` tags while handling split text nodes, partial selections, and re-toggling.

---

### 8. Resizable Split-Pane Layout
**Description:** A layout with two or more panels separated by draggable dividers that resize the panels proportionally, supporting both horizontal and vertical splits.
**Core JS Concepts:** PointerEvents, CSS grid/flex manipulation, cursor style management, min/max clamping
**Difficulty:** Intermediate
**Unique Challenge:** Preventing layout jank during resize by calculating deltas from `pointermove` rather than reading layout from the DOM (which triggers reflow).

---

### 9. Command Palette (⌘K) [RARE]
**Description:** A VS Code / Linear-style command palette that opens on ⌘K, fuzzy-searches a registered list of commands, shows keyboard shortcuts, and executes them.
**Core JS Concepts:** Keyboard events, fuzzy search algorithm, command pattern, CSS transitions
**Difficulty:** Intermediate
**Unique Challenge:** Implementing a good fuzzy-match algorithm (e.g. Smith-Waterman scoring) that ranks results by relevance, not just substring inclusion.

---

### 10. Drag-to-Reorder Kanban Board
**Description:** A Trello-style board where cards can be dragged between columns and reordered within columns, with smooth animated reflow.
**Core JS Concepts:** Drag and Drop API, FLIP animation technique, LocalStorage persistence, event delegation
**Difficulty:** Advanced
**Unique Challenge:** Computing the "drop target" position mid-drag — determining whether the dragged card should insert before or after the hovered card based on the cursor's Y offset within the target element.

---

### 11. Raycast-style Spotlight Search [RARE]
**Description:** An OS-level-feeling search interface that indexes headings, links, and metadata from the current page, supports fuzzy matching, and navigates or executes actions.
**Core JS Concepts:** DOM traversal, scoring algorithms, keyboard navigation, CSS backdrop-filter
**Difficulty:** Advanced
**Unique Challenge:** Building a live index of page content using TreeWalker + MutationObserver so search results stay accurate even as the page's DOM changes dynamically.

---

## 🎮 Category 2 — Games

### 12. Snake [CLASSIC]
**Description:** The classic growing-snake game on a grid with increasing speed, self-collision detection, and a high-score tracker.
**Core JS Concepts:** setInterval, 2D array grid, modular arithmetic for wrapping, KeyboardEvent
**Difficulty:** Beginner
**Unique Challenge:** Ensuring the direction can't reverse 180° in a single frame — requires a pending-direction queue so rapid double-key presses don't kill the snake.

---

### 13. Tetris [CLASSIC]
**Description:** Full Tetris implementation with all 7 tetrominoes, wall-kick rotation (SRS), line clearing, level progression, and ghost piece.
**Core JS Concepts:** Canvas 2D, matrix rotation, collision detection, requestAnimationFrame with delta-time
**Difficulty:** Intermediate
**Unique Challenge:** Implementing the Super Rotation System (SRS) wall-kick offsets correctly — each piece has a specific table of 4 kick attempts per rotation.

---

### 14. Nonogram / Picross Puzzle
**Description:** A logic puzzle game where players fill cells in a grid based on row/column number clues to reveal a hidden pixel image.
**Core JS Concepts:** 2D array state, CSS Grid rendering, right-click events, puzzle validation
**Difficulty:** Intermediate
**Unique Challenge:** Generating valid puzzles with unique solutions programmatically — requires a constraint-propagation solver to verify uniqueness.

---

### 15. Minesweeper with Procedural Generation [CLASSIC]
**Description:** Minesweeper where mines are placed only *after* the first click to guarantee a safe start, with a chord-click mechanic and win-state detection.
**Core JS Concepts:** BFS flood-fill, event delegation, deferred mine placement, recursive reveal
**Difficulty:** Intermediate
**Unique Challenge:** Implementing "chording" (clicking a revealed number with the right count of adjacent flags reveals remaining neighbours) which requires tracking per-cell flag counts.

---

### 16. Wordle Clone with Hard Mode & Statistics
**Description:** Daily Wordle with hard mode (all revealed hints must be used), share emoji output, and a persistent stats chart.
**Core JS Concepts:** String analysis, LocalStorage, CSS animations, keyboard layout rendering
**Difficulty:** Beginner
**Unique Challenge:** The "flip-then-reveal" animation requires a two-step CSS class addition with a precise delay so the tile color is only shown after the flip completes, not before.

---

### 17. 2D Platformer with Physics [RARE]
**Description:** A side-scroller with AABB collision, coyote-time jump, variable jump height, moving platforms, and a tilemap loaded from a JSON level file.
**Core JS Concepts:** Canvas 2D, game loop, AABB collision, tilemap rendering, spritesheet animation
**Difficulty:** Advanced
**Unique Challenge:** Resolving AABB collision responses correctly — determining the minimum translation vector to push the player out of a tile without clipping through thin tiles at high speed (tunneling).

---

### 18. Tower Defense Engine
**Description:** A wave-based tower defense game with enemies following a path, multiple tower types with range/damage stats, and a level editor.
**Core JS Concepts:** Canvas 2D, pathfinding (A*), object pooling, event-driven wave manager
**Difficulty:** Advanced
**Unique Challenge:** Implementing tower targeting that correctly "leads" a moving enemy (predicting its future position) so projectiles actually hit.

---

### 19. Dungeon Crawler (Roguelite) [RARE]
**Description:** A tile-based roguelite dungeon crawler with procedurally generated rooms, FOV rendering, turn-based combat, and item system.
**Core JS Concepts:** Canvas 2D, BSP/random room generation, recursive shadowcasting for FOV, entity-component pattern
**Difficulty:** Advanced
**Unique Challenge:** Implementing recursive shadowcasting for field-of-view — the algorithm has tricky edge cases where shadow boundaries split tiles and must be handled with epsilon offsets.

---

### 20. Chess with Legal Move Validation
**Description:** A fully playable chess game with all special moves (castling, en passant, promotion), legal move filtering, and check/checkmate detection.
**Core JS Concepts:** 2D array board representation, move generation, king safety check, SVG piece rendering
**Difficulty:** Advanced
**Unique Challenge:** Filtering pseudo-legal moves to legal ones requires simulating every candidate move and checking if the king ends in check — performance matters since you test up to 218 moves per position.

---

### 21. Sokoban Puzzle Game
**Description:** The classic box-pushing puzzle with undo history, level selection, and a move counter.
**Core JS Concepts:** 2D array state, immutable state snapshots for undo, CSS grid rendering, JSON level format
**Difficulty:** Intermediate
**Unique Challenge:** The undo system must store full immutable board snapshots (not move logs) because Sokoban moves are not easily reversible (you can't "unpush" a box against a wall).

---

### 22. Typing Speed Trainer with WPM Graph
**Description:** A real-time typing test that measures WPM/accuracy, highlights errors character-by-character, and plots a live WPM-over-time sparkline.
**Core JS Concepts:** Input events, string diff comparison, requestAnimationFrame, Canvas sparkline
**Difficulty:** Beginner
**Unique Challenge:** Rendering the character-by-character diff overlay in sync with the user's cursor without using a textarea's native cursor — requires a mirrored div with custom cursor simulation.

---

### 23. Gravity Pong (Curved Trajectories)
**Description:** Pong where the ball is affected by a gravitational field that can be repositioned by the player, making trajectories arc unpredictably.
**Core JS Concepts:** Canvas 2D, verlet integration, vector math, collision response
**Difficulty:** Intermediate
**Unique Challenge:** Implementing physically plausible ball-to-paddle collision normals — the angle of reflection must account for the paddle's velocity to allow "spin" shots.

---

### 24. Infinite Runner with Procedural Terrain
**Description:** A side-scrolling infinite runner with procedurally generated ground (Perlin noise), obstacles, and parallax background layers.
**Core JS Concepts:** Canvas 2D, Perlin noise, object pooling, parallax rendering, delta-time game loop
**Difficulty:** Advanced
**Unique Challenge:** Seamlessly tiling procedurally generated chunks — the next chunk must begin exactly where the previous ended, requiring stateful noise seeding with the chunk index.

---

### 25. Cellular Automaton Explorer
**Description:** An interactive playground for Conway's Game of Life and other rules (Brian's Brain, Langton's Ant, etc.), with play/pause, step, and pattern import.
**Core JS Concepts:** Canvas 2D, typed arrays (Uint8Array for grid), double-buffering, bitwise operations
**Difficulty:** Intermediate
**Unique Challenge:** Achieving 60fps on a 256×256 grid — requires using a flat `Uint8Array` instead of a 2D array, and computing neighbor counts with pre-shifted row references to avoid inner-loop bounds checks.

## 📈 Category 3 — Data Visualization & Canvas / SVG

### 26. Live Bar Chart Race
**Description:** Animates a horizontal bar chart where bars grow, shrink, and reorder over time as data values change — like the famous "country GDP over time" visualizations.
**Core JS Concepts:** Canvas or SVG, requestAnimationFrame, lerp (linear interpolation), data normalization
**Difficulty:** Intermediate
**Unique Challenge:** Smoothly interpolating both bar *width* and bar *vertical position* simultaneously — the Y-axis reordering must be animated with position lerp, not an instant jump.

---

### 27. SVG Force-Directed Graph [RARE]
**Description:** An interactive network graph where nodes repel each other and edges attract connected nodes, reaching an equilibrium layout — built entirely with SVG.
**Core JS Concepts:** SVG element creation, force simulation (Verlet/Euler), drag interaction, quadtree for performance
**Difficulty:** Advanced
**Unique Challenge:** Implementing the Barnes-Hut approximation with a quadtree to reduce repulsion calculations from O(n²) to O(n log n) — without this, graphs with 200+ nodes become unusable.

---

### 28. Heatmap Calendar (GitHub-style)
**Description:** A contribution-style calendar heatmap that visualizes activity data per day for a full year, with hover tooltips and a color scale.
**Core JS Concepts:** SVG generation, Date API, color interpolation (HSL), tooltip positioning
**Difficulty:** Intermediate
**Unique Challenge:** Correctly computing which week-column each day belongs to while handling year boundaries — the first week of January may start mid-column from the previous year's leftover days.

---

### 29. Real-Time Candlestick Chart [RARE]
**Description:** A financial OHLC candlestick chart that streams live price data (from a WebSocket or a mock), auto-scrolls, and supports pan/zoom interaction.
**Core JS Concepts:** Canvas 2D, WebSocket or setInterval mock, coordinate mapping, pinch-to-zoom
**Difficulty:** Advanced
**Unique Challenge:** Implementing the coordinate-space transform so pan/zoom operates in data-space (price × time) rather than screen-space, and correctly recalculating the visible data window on each frame.

---

### 30. Treemap Visualizer
**Description:** Renders hierarchical data as a zoomable treemap using the Squarified algorithm — click a node to drill down, breadcrumb for back-navigation.
**Core JS Concepts:** Recursive layout algorithms, Canvas or SVG, click-to-zoom transitions, JSON tree data
**Difficulty:** Intermediate
**Unique Challenge:** Implementing the Squarified algorithm correctly — it must partition rectangles row-by-row choosing the orientation that minimizes the worst aspect ratio in each row.

---

### 31. Animated Sankey Diagram [RARE]
**Description:** A Sankey flow diagram where animated particles travel along the flow paths to visually represent volume — built with SVG paths and requestAnimationFrame.
**Core JS Concepts:** SVG `<path>` with cubic bezier, `getPointAtLength()`, particle system, data normalization
**Difficulty:** Advanced
**Unique Challenge:** Using `SVGPathElement.getPointAtLength(t)` to move particles along arbitrary bezier curves at a constant speed, requiring arc-length reparameterization because `t` is not proportional to distance.

---

### 32. Radar / Spider Chart
**Description:** An interactive radar chart with N configurable axes, animated fill, comparison mode for two datasets, and live data editing.
**Core JS Concepts:** SVG, polar coordinate math, CSS transitions, data binding pattern
**Difficulty:** Intermediate
**Unique Challenge:** Calculating the polygon's SVG `points` attribute from polar-to-cartesian conversions, and handling the special case where N=3 (equilateral triangle) vs N=8 (octagon) with correct angle offsets.

---

### 33. World Choropleth Map [RARE]
**Description:** A world map where countries are colored by a data value (e.g. population, GDP) using GeoJSON paths projected and rendered to SVG, with a color legend.
**Core JS Concepts:** SVG path rendering, GeoJSON parsing, map projection math (equirectangular/Mercator), color scale
**Difficulty:** Advanced
**Unique Challenge:** Implementing a map projection from scratch — converting (longitude, latitude) pairs into screen (x, y) coordinates using the Mercator projection formula, and correctly scaling/centering the result.

---

### 34. Live CSV → Chart Transformer
**Description:** Drop a CSV file onto the page; it auto-detects numeric columns and lets you build line, bar, or scatter charts with a live column picker — no upload, pure client-side.
**Core JS Concepts:** FileReader API, CSV parsing, dynamic chart rendering, drag-and-drop file handling
**Difficulty:** Intermediate
**Unique Challenge:** Heuristically detecting column types from CSV data — distinguishing dates, integers, floats, and strings by sampling values, then suggesting appropriate axis assignments.

## 🌐 Category 4 — APIs & Async (Fetch, REST, WebSockets)

### 35. REST API Explorer (Postman-lite)
**Description:** A browser tool where users can build and fire HTTP requests (method, headers, body), view responses with syntax highlighting, and save a history of requests.
**Core JS Concepts:** Fetch API, CORS awareness, JSON formatting, LocalStorage for history
**Difficulty:** Intermediate
**Unique Challenge:** Handling CORS — the tool can only reach APIs that allow browser cross-origin requests, requiring clear UX messaging when a request fails due to CORS vs network error vs 4xx/5xx.

---

### 36. GitHub Profile Dashboard
**Description:** Enter a GitHub username and get a visual dashboard: top languages, pinned repos, commit activity, follower graph — all from the public GitHub REST API.
**Core JS Concepts:** Fetch API, Promise.all, data aggregation, Canvas charts
**Difficulty:** Beginner
**Unique Challenge:** Aggregating language data from multiple repo responses (each returns its own language object) using `Promise.all` and merging the results — requires careful rate-limit handling.

---

### 37. WebSocket Chat Room
**Description:** A real-time multi-user chat that connects to a WebSocket server, shows typing indicators, online presence, and message delivery receipts.
**Core JS Concepts:** WebSocket API, message queuing, reconnect backoff, virtual scroll for message history
**Difficulty:** Intermediate
**Unique Challenge:** Implementing exponential-backoff reconnection logic — when the socket drops, retry after 1s, 2s, 4s, 8s… up to a cap, without creating multiple overlapping reconnect timers.

---

### 38. Server-Sent Events Live Feed [RARE]
**Description:** A live news-ticker or stock-price dashboard powered by Server-Sent Events (SSE) — demonstrates the often-overlooked alternative to WebSockets for one-way streams.
**Core JS Concepts:** EventSource API, event parsing, auto-reconnect behavior, DOM update batching
**Difficulty:** Intermediate
**Unique Challenge:** Batching rapid SSE events (e.g. 50/sec) into a single DOM update per frame using a buffer + `requestAnimationFrame` flush, preventing layout thrashing.

---

### 39. OAuth PKCE Flow from Scratch [RARE]
**Description:** Implements the full OAuth 2.0 Authorization Code flow with PKCE, using the Web Crypto API to generate the code verifier/challenge — no libraries.
**Core JS Concepts:** Web Crypto API (SHA-256, randomBytes), URL manipulation, sessionStorage, redirect handling
**Difficulty:** Advanced
**Unique Challenge:** Generating the PKCE code challenge: hash the random verifier with SHA-256 (Web Crypto), base64url-encode the binary result (without padding), and correctly reconstruct the state after the OAuth redirect.

---

### 40. GraphQL Query Builder & Tester [RARE]
**Description:** A visual tool where users compose GraphQL queries by clicking field checkboxes on a schema introspection tree, then fire the query and see results.
**Core JS Concepts:** Fetch (POST JSON), recursive tree rendering, GraphQL introspection query, string template generation
**Difficulty:** Advanced
**Unique Challenge:** Parsing the GraphQL introspection schema response recursively — schemas have circular type references (e.g. a type's fields reference other types) requiring a reference map to avoid infinite loops.

---

### 41. Paginated Infinite API Feed
**Description:** Fetches a paginated API, appending results as the user scrolls using IntersectionObserver on a sentinel element — with loading skeletons and error retry.
**Core JS Concepts:** IntersectionObserver, Fetch, loading state management, skeleton screens
**Difficulty:** Beginner
**Unique Challenge:** Preventing duplicate fetches when the IntersectionObserver fires multiple times in quick succession — requires a `isFetching` guard flag that's reset only after the fetch + render completes.

---

### 42. Multi-Source News Aggregator
**Description:** Fetches headlines from multiple public news APIs in parallel, deduplicates stories by title similarity, and ranks them by recency and source diversity.
**Core JS Concepts:** Promise.allSettled, string similarity (Levenshtein or Jaccard), deduplication, sorting
**Difficulty:** Intermediate
**Unique Challenge:** Deduplicating cross-source stories via fuzzy title matching — computing pairwise Jaccard similarity on tokenized titles in O(n²) is slow for large feeds; requires a hash-bucketing strategy.

## 🔌 Category 5 — Browser APIs

### 43. Geolocation Heatmap
**Description:** Tracks the user's device GPS position over time, plots each point on a canvas, and renders a radial intensity heatmap overlay.
**Core JS Concepts:** Geolocation API (watchPosition), Canvas 2D, radial gradient compositing, coordinate normalization
**Difficulty:** Intermediate
**Unique Challenge:** Implementing the heatmap glow by drawing a radial gradient for each point using `destination-over` or `lighter` compositing and then applying a threshold colormap pass — without going through a full image pixel loop.

---

### 44. Clipboard Manager
**Description:** A floating widget that intercepts copy events, stores a history of 20 recent clipboard entries (text and images), and lets the user re-paste any previous item.
