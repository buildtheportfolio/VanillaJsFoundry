Cellular Automaton Explorer

Life-like B/S rules and 1D elementary rules on a flat Uint8Array grid.

Generation 0 Population 0 Grid 128x128 Zoom 1x

Draw: drag (right-drag erases). Pan: Shift-drag, middle button, or Pan tool. Zoom: wheel, pinch, + / -. Keys: Space play, S step, R random, C clear, F fit, T rotate pattern.

Mode

Rule (B/S)

Birth on neighbour counts after B, survive on counts after S.

Elementary rule

Each button is a left-centre-right neighbourhood and the next cell it produces. Each generation becomes a new row.
